# 6. Доменные data-продукты

Элементы Data Mesh применяются точечно: выделяем доменные наборы данных как продукты с владельцем, контрактом и потребителями. Полноценный Mesh на всю организацию не строится.

| Data product | Домен (BIAN / бизнес) | Основные данные | Владелец | Потребители | SLA / контракт |
|--------------|-----------------------|-----------------|----------|-------------|----------------|
| **Customer 360** | Party Data Management / Customer Profile | Клиент (golden), сегмент, контакты, согласия, связи с договорами и счетами | Data Office + CRM-домен | CRM, КЦ, BI, маркетинг, риск-менеджмент | Актуальность ≤ 15 мин для критичных атрибутов, полный lineage |
| **Account & Balance** | Current Account / Deposit Account | Счета, ежедневные остатки, статусы, валюта | Core Banking domain | BI, Финансовый департамент, Риски, Регулятор (через витрины) | Ежедневный срез к 07:00, сверка с Core |
| **Transaction History** | Account Transaction / Payment Execution | Унифицированные транзакции двух банков, каналы, типы операций | Core + Cards domain | Антифрод, BI, Риски, data science | История ≥ 5 лет в Lakehouse, витрины T-1 |
| **Loan Portfolio** | Loan / Credit Facility | Кредиты, остатки, ставки, статусы, просрочка | Credit / Risk domain | Риск-менеджмент, Финансовый департамент, Регулятор, BI | Ежедневный портфель, контрольные сверки |
| **Customer Interactions** | Customer Contact / Case Management | Обращения, темы, статусы, каналы, результаты | Контактный центр + CRM | КЦ, BI, качество сервиса, маркетинг | Привязка к единому customer_id, T-1 |

## Как это работает в архитектуре

- Каждый data-product имеет **владельца** (Data Owner + Steward).
- Контракт (schema + SLA + DQ-правила) регистрируется в **DataHub**.
- Физически продукт может жить в DWH-витринах и/или Lakehouse Gold-слое.
- Потребители получают доступ через BI, API или SQL (Trino), а не через прямой доступ к исходным системам.
- Это позволяет постепенно двигаться к более децентрализованной модели, не ломая текущую централизованную платформу.
